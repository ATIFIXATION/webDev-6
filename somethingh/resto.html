Architecture
Single-file SPA. All menu data lives in the MENU constant. Pages are toggled with CSS transitions — no framework needed.
testcafe/ ├── assets/ │ ├── logo.svg │ └── favicon.png ├── index.html ← you are here ├── README.md └── data/ └── menu.json ← optional static export
